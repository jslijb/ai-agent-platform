# AI Agent / LLM 应用方向高薪 JD 特征分析报告（50k+ 月薪）

> **调研时间**：2026年8月  
> **数据来源说明**：由于招聘网站反爬限制，无法直接批量抓取100份JD原始文本。本报告基于以下数据源综合分析：  
> 1. LinkedIn 中国区 AI Agent 相关岗位搜索结果（实时获取，确认岗位存在）  
> 2. Boss直聘/猎聘/拉勾等平台公开岗位信息（部分可获取）  
> 3. 各大厂官网招聘页公开信息（字节/阿里/腾讯/百度/华为/美团/京东/小红书/快手/拼多多/蚂蚁/商汤/旷视/第四范式等）

> 5. **标注规则**：所有统计数据均标注 `[估计值]` 或 `[验证值]`，验证值来自可直接确认的数据  
>   
> **估计方法**：基于可获取的样本（约30份可验证JD）+ 行业趋势外推，置信度约75-85%
