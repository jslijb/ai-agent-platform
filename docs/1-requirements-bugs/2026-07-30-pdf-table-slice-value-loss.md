# 踩坑：PDF 表格切片丢失数值（2026-07-30）

## 现象
L1/L3/L4 数值类查询 CR 严重不足（L1=0.67, L3=0.30, L4=0.50）。

## 根因
1. PDF 表格切片破坏行列结构，数值与指标名分到不同chunk
2. text-cleaner 主动破坏表格（压缩多空格、删 | 分隔行）
3. BM25 预处理删除千分位逗号、小数点、|，数字格式受损
4. 表格向量化 2000 字符截断丢表头

## 教训
- 数值类查询不应走向量检索，应走SQL精确查询
- PDF表格必须保持行列完整性

## 改进措施
- R001：五表双轨制，数值类走SQL，非数值走向量
- pdf_extractor.py 提取三张主表入PostgreSQL
- 已记录到 ADR-011

## 关联
- 需求：R001/R010/R011/R012
- ADR：ADR-011
