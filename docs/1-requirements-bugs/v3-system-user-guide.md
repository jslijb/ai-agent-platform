## 第一章 系统总览

### 1.1 系统简介

AI Agent Platform V3.0 是一个企业级智能体平台，核心能力包括：

- **智能问答**：基于你上传的文档，AI 给出有引用来源的精准回答
- **Agent 对话**：AI 不仅能回答问题，还能调用工具执行操作（查行情、算指标、做合规检查）
- **OA/CRM 操作**：用自然语言操作办公系统（请假、审批、创建客户、推进商机等）
- **多端访问**：Web 浏览器、微信小程序、手机 App、飞书、钉钉均可使用

### 1.2 系统访问地址

| 端 | 访问方式 | 地址 | 说明 |
|----|---------|------|------|
| Web 端 | 浏览器 | http://localhost | 主入口，功能最全 |
| 微信小程序 | 微信扫码 | 小程序码（见第三章） | 核心问答+Agent |
| 安卓/iOS App | 手机安装 | APK/IPA 分发 | 核心问答+Agent |
| 飞书机器人 | 飞书对话 | 搜索机器人名称 | Agent 对话+审批 |
| 钉钉机器人 | 钉钉对话 | 群内 @机器人 | Agent 对话 |
| Odoo OA | 浏览器 | http://localhost/oa/ | 审批/通知/日程/考勤 |
| Twenty CRM | 浏览器 | http://localhost/crm/ | 客户/商机/合同/报表 |

### 1.3 账号体系

系统使用统一账号体系，一个账号可登录所有端：

| 信息 | 说明 |
|------|------|
| 注册方式 | 邮箱 + 密码 |
| 登录方式 | 邮箱 + 密码 |
| 默认测试账号 | jslijb@163.com |
| 用户 ID | 69ea0f70-00a0-426b-aa5f-0e198d0f69d3 |

> **注意**：首次使用需先在 Web 端注册账号，其他端使用同一账号登录。

### 1.4 系统健康检查

在使用系统前，建议先确认系统是否正常运行：

1. 打开浏览器，访问 http://localhost/api/health
2. 看到以下 JSON 表示系统正常：

```json
{
  "status": "up",
  "checks": {
    "database": { "status": "up" },
    "embedding": { "status": "up", "latency": 45 },
    "reranker": { "status": "up", "latency": 12 },
    "llm": { "status": "up", "latency": 230 }
  }
}
```

| 状态 | 含义 |
|------|------|
| up | 正常 |
| degraded | 部分功能不可用，核心功能仍可用 |
| down | 不可用，请联系管理员 |

## 第二章 Web 端使用指南

### 2.1 注册与登录

#### 功能概述

首次使用系统需要注册账号，注册后可登录所有端。

#### 前置条件

- 系统已部署并运行（健康检查返回 `up`）
- 浏览器推荐使用 Chrome/Edge 最新版

#### 操作步骤

**Step 1**：打开浏览器，在地址栏输入 `http://localhost`，按回车

**Step 2**：系统自动跳转到登录页面 `/login`

**Step 3（首次使用）**：点击页面上的「注册」链接
- 在「邮箱」输入框中输入你的邮箱地址（如 `user@example.com`）
- 在「密码」输入框中输入密码（至少 8 位）
- 在「确认密码」输入框中再次输入密码
- 点击「注册」按钮
- 看到提示"注册成功"，自动跳转回登录页

**Step 4（登录）**：
- 在「邮箱」输入框中输入注册时的邮箱
- 在「密码」输入框中输入密码
- 点击「登录」按钮

#### 预期结果

- 登录成功后，页面跳转到首页 `/`
- 页面顶部显示你的邮箱头像
- 页面展示功能入口卡片（RAG 智能问答、Agent 对话、文档管理、评估管理等）

#### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 页面打不开 | 系统未启动或端口不通 | 检查 Docker 容器是否运行：`docker ps` |
| 注册失败提示"邮箱已存在" | 该邮箱已注册 | 直接登录，或使用其他邮箱 |
| 登录后跳回登录页 | AUTH_SECRET 配置不一致 | 联系管理员检查配置 |

### 2.2 RAG 智能问答

#### 功能概述

RAG（检索增强生成）问答：你提出问题，系统从你上传的文档中检索相关内容，AI 基于检索结果生成答案，并标注引用来源。适合查询财报数据、研报内容、法规条款等。

#### 前置条件

- 已登录系统
- 系统中已有相关文档（如果文档库为空，问答会提示"未找到相关文档"）

#### 操作步骤

**Step 1**：登录后，在首页点击「RAG 智能问答」卡片，进入 `/chat` 页面

**Step 2**：在页面底部的输入框中输入你的问题，例如：
- "贵州茅台 2025 年营收是多少？"
- "招商银行的风险控制措施有哪些？"
- "中国平安的 ROE 趋势如何？"

**Step 3**：按回车或点击发送按钮

**Step 4**：观察 AI 回答过程
- 页面会实时流式显示 AI 的回答（逐字出现，类似 ChatGPT）
- 回答中会标注引用来源，格式如 `[文档名, 第X页]`
- 引用来源可点击查看原文

**Step 5**：在回答下方的输入框继续追问（多轮对话）

#### 检索模式说明

系统支持 4 种检索模式，默认使用 hybrid（混合模式）：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| hybrid（默认） | 向量检索 + BM25 关键词检索 + 融合排序 | 通用场景，推荐使用 |
| dense | 纯向量语义检索 | 语义相似度高的查询 |
| sparse | 纯 BM25 关键词检索 | 精确关键词匹配 |
| graph | 知识图谱推理 | 多跳关系推理（如"A公司的子公司有哪些"） |

> **提示**：普通用户无需关心检索模式，系统会自动选择最优模式。高级用户可在对话中指定模式。

#### 预期结果

```
用户: 分析招商银行 2025 年年报中的核心经营指标

系统回答:
根据招商银行 2025 年年报 [招商银行_2025年年度报告.pdf, P.15]:

1. 营业收入: 3,456.78 亿元，同比增长 5.2%
2. 净利润: 1,482.35 亿元，同比增长 6.1%
3. 不良贷款率: 0.95%，较上年下降 0.02 个百分点
4. 拨备覆盖率: 445.32%
5. ROE: 16.28%

引用来源:
[1] 招商银行_2025年年度报告.pdf - 核心经营指标章节
[2] 招商银行_2025年年度报告.pdf - 风险管理章节
```

#### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 回答"未找到相关文档" | 文档库中没有相关文档 | 先上传相关文档（见 2.4 节） |
| 回答内容与文档不符 | 检索到了不相关的段落 | 尝试更精确的问题描述 |
| 回答速度很慢 | embedding/reranker 服务延迟高 | 检查 8011/8010 端口服务是否正常 |
| 回答中出现"非常抱歉，您问的问题受国家政策、法规影响" | 触发合规拒绝 | 该问题属于合规限制范围，换一个问题 |

### 2.3 Agent 对话

#### 功能概述

Agent 对话比 RAG 问答更强大：AI 不仅能回答问题，还能调用工具执行操作。例如查行情、算技术指标、做合规检查、操作 OA/CRM 等。

#### 前置条件

- 已登录系统
- Agent 相关工具服务正常运行

#### 操作步骤

**Step 1**：在 `/chat` 页面，直接输入问题即可。系统会自动判断使用 RAG 还是 Agent。

**Step 2**：Agent 会显示执行过程，包括调用了哪些工具、每个工具的耗时

**Step 3**：Agent 返回最终结果

#### Agent 类型说明

| Agent | 名称 | 用途 | 示例问题 |
|-------|------|------|---------|
| Orchestrator | 主控编排 | 接收查询，路由到专项 Agent | 所有问题的入口 |
| Researcher | 研究员 | 投研分析、行业研究 | "分析白酒行业竞争格局" |
| Quant | 量化分析师 | 技术指标计算 | "计算贵州茅台的 MA20 和 RSI" |
| Compliance | 合规官 | 交易合规检查 | "检查买入 600036 是否合规" |
| General | 通用助手 | 日常问答、文本摘要 | "总结这份研报的核心观点" |

#### Agent 对话示例

**量化分析**：
```
用户: 计算招商银行的 MA20 和 MACD
Agent: [调用 calculate_ma 工具] [调用 calculate_rsi 工具]
结果: MA20 = 35.62 元, MACD = -0.23 (死叉状态)
```

**合规检查**：
```
用户: 买入 1000 股 600036 是否合规？
Agent: [调用 check_trade_compliance 工具]
结果: 合规检查通过。600036(招商银行) 不在受限股票名单中，买入数量在持仓限制范围内。
```

**多轮对话**：
```
第1轮: 用户: "贵州茅台的最新股价是多少？"
       Agent: "贵州茅台(600519)最新股价为 1,856.00 元..."

第2轮: 用户: "它的 PE 呢？"  ← 不需要重复说明股票
       Agent: "贵州茅台当前市盈率(PE-TTM)为 28.5..."
```

#### 预期结果

- Agent 正确理解意图并调用对应工具
- 每步执行过程和耗时可见
- 最终返回准确结果

#### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| Agent 回答"服务不可用" | LLM API Key 未配置或额度用尽 | 联系管理员检查 API Key |
| 工具调用超时 | 数据源接口响应慢 | 稍后重试 |
| Agent 误解意图 | 问题表述不够清晰 | 换一种说法重新描述 |

### 2.4 知识库管理（文档上传）

#### 功能概述

上传文档到知识库，AI 才能基于文档内容回答问题。支持 PDF、TXT、Markdown 格式。

#### 前置条件

- 已登录系统
- 准备好要上传的文档文件

#### 操作步骤

**Step 1**：登录后，在首页点击「文档管理」卡片，进入 `/dashboard` 页面

**Step 2**：在控制台页面，点击「上传文档」按钮

**Step 3**：在弹出的文件选择器中，选择本地文件（支持多选）

**Step 4**：选择文档类型：
- **研报** (research_report) — 有效期 90 天
- **财报** (financial_report) — 有效期 365 天
- **法规** (regulation) — 永不过期
- **通用** (general) — 有效期 180 天

**Step 5**：点击「确认上传」按钮

**Step 6**：等待系统处理。处理流程：
```
上传文件 → PDF解析 → 智能切片 → 向量化(BGE-M3) → 存入PostgreSQL
                              ↓
              实体关系抽取 → 存入Neo4j图谱
                              ↓
              BM25索引构建 → 存入内存索引
```

#### 预期结果

- 上传成功后，文档列表中出现新记录
- 文档状态从 `processing`（处理中）变为 `completed`（已完成）
- 处理完成后，该文档内容可被 RAG 问答检索到

#### 支持的文档格式

| 格式 | 说明 |
|------|------|
| PDF | 年报、研报、公告（支持表格提取） |
| TXT | 纯文本文件 |
| Markdown | .md 格式文件 |

#### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 上传后状态为 `failed` | PDF 可能是扫描件（图片型） | 使用文字型 PDF，或先做 OCR 处理 |
| 处理时间很长 | 文档页数多或表格复杂 | 耐心等待，通常 1-5 分钟 |
| 上传后问答仍找不到 | 文档还在处理中 | 等状态变为 `completed` 后再试 |

### 2.5 评估管理

#### 功能概述

评估功能用于测试 AI 回答质量。触发评估后，系统自动运行测试问题集，生成评估报告，包含准确率、完整率等指标。

#### 前置条件

- 已登录系统
- 系统中已有文档数据
- 评估数据集已配置（qa-golden.json）

#### 操作步骤

**Step 1**：在首页点击「评估管理」卡片，进入评估页面

**Step 2**：点击「触发评估」按钮

**Step 3**：选择评估参数：
- 评估器：selfimpl（自实现评估器）
- 测试集：qa-golden（标准测试集）
- 评估维度：CP（正确性）、CR（完整率）、AR（答案相关性）

**Step 4**：点击「开始评估」

**Step 5**：等待评估完成（通常 5-15 分钟）

**Step 6**：查看评估报告，包含各维度得分和综合得分

#### 预期结果

- 评估报告显示各维度得分
- 综合得分 ≥ 0.82 为达标
- 报告可下载为 JSON 文件

#### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 评估失败 | LLM 额度用尽 | 检查 API Key 额度 |
| 评分偏低 | 文档数据不完整 | 补充上传相关文档 |

### 2.6 历史对话

#### 功能概述

查看和继续之前的对话记录。系统自动保存所有对话历史。

#### 前置条件

- 已登录系统
- 之前有过对话记录

#### 操作步骤

**Step 1**：在 `/chat` 页面，点击左侧边栏的「历史对话」

**Step 2**：浏览历史对话列表，每条记录显示：
- 对话标题（根据首条消息自动生成）
- 对话时间
- 对话轮数

**Step 3**：点击某条历史对话，进入该对话

**Step 4**：在对话底部的输入框继续提问，AI 会基于之前的上下文回答

#### 预期结果

- 历史对话列表正确显示
- 点击后能加载完整对话内容
- 继续对话时 AI 能理解上下文

#### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 显示"暂无历史对话" | AUTH_SECRET 配置不一致导致 JWT 验证失败 | 联系管理员确保 .env.local / .env.docker / docker-compose.yml 三处 AUTH_SECRET 一致 |
| 历史对话加载慢 | 数据库查询慢 | 稍等片刻 |

## 第三章 微信小程序使用指南

### 3.1 功能概述

微信小程序是 V3.0 新增的移动端入口，提供核心问答和 Agent 对话功能，方便在微信中随时使用 AI 助手。

### 3.2 前置条件

- 手机已安装微信
- 已在 Web 端注册账号
- 系统已部署微信小程序

### 3.3 操作步骤

**Step 1**：打开微信，点击底部「发现」→「小程序」

**Step 2**：点击右上角搜索图标，搜索"AI Agent"或扫描小程序码

**Step 3**：首次使用需登录：
- 输入在 Web 端注册的邮箱和密码
- 点击「登录」按钮

**Step 4**：登录后进入首页，看到功能入口：
- 智能问答
- Agent 对话
- 历史对话

**Step 5**：点击「智能问答」，在输入框输入问题，点击发送

**Step 6**：AI 实时流式回答，体验与 Web 端一致

**Step 7**：点击底部「历史」标签，查看历史对话

### 3.4 预期结果

- 小程序正常加载，界面显示正常
- 问答功能与 Web 端一致（流式响应）
- 历史对话与 Web 端同步

### 3.5 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 小程序打不开 | 小程序未发布或网络问题 | 检查网络，或联系管理员 |
| 登录失败 | 账号未在 Web 端注册 | 先在 Web 端注册 |
| 回答不是流式的 | 小程序 SSE 兼容问题 | 检查小程序版本是否最新 |

### 3.6 注意事项

- 微信小程序不支持文档上传和评估管理，需在 Web 端操作
- 小程序单次对话有字数限制（约 2000 字），超长回答会被截断
- 小程序后台运行时可能断开连接，回到前台需重新连接

## 第四章 安卓/iOS App 使用指南

### 4.1 功能概述

安卓/iOS App 是 V3.0 新增的移动端入口，基于 Capacitor 封装 Web 端，提供核心问答和 Agent 对话功能。

### 4.2 前置条件

- 安卓 8.0+ 或 iOS 14+ 设备
- 已在 Web 端注册账号
- 已安装 App（APK 或 TestFlight 分发）

### 4.3 安装步骤

**安卓**：
1. 下载 APK 文件
2. 点击安装（可能需要允许"未知来源"安装）
3. 安装完成后打开 App

**iOS**：
1. 通过 TestFlight 链接安装
2. 安装完成后打开 App

### 4.4 操作步骤

**Step 1**：打开 App，首次使用需登录
- 输入在 Web 端注册的邮箱和密码
- 点击「登录」

## 第九章 AI Agent 操作 OA/CRM 使用指南

### 9.1 功能概述

这是 V3.0 的核心新能力：**用自然语言操作办公系统**。你不需要登录 Odoo 或 Twenty，直接对 AI Agent 说一句话，Agent 就能帮你完成操作。

| 审批流程 | "审批李明的请假申请" | Odoo OA |

## 第十章 常见问题与故障排除

### 10.1 系统级问题

| 问题 | 排查步骤 | 解决方案 |
|------|---------|---------|
| 系统完全无法访问 | 1. 检查 Docker Desktop 是否运行 2. `docker ps` 查看容器状态 | 启动 Docker Desktop，运行 `docker compose up -d` |
| 部分功能不可用 | 1. 访问 /api/health 检查各组件状态 2. 查看具体哪个组件 down | 重启对应容器：`docker restart <容器名>` |
| 登录后跳回登录页 | AUTH_SECRET 配置不一致 | 确保 .env.local / .env.docker / docker-compose.yml 三处 AUTH_SECRET 相同 |
| 历史对话不显示 | JWT 验证失败（同上） | 同上，修复 AUTH_SECRET 配置 |

### 10.2 RAG 问答问题

| 问题 | 排查步骤 | 解决方案 |
|------|---------|---------|
| "未找到相关文档" | 1. 检查是否上传过文档 2. 检查文档状态是否 completed | 上传文档并等待处理完成 |
| 回答质量差 | 1. 检查文档是否完整 2. 尝试更精确的问题 | 上传更多相关文档，优化问题表述 |
| 回答速度慢 | 1. 检查 embedding(8011)/reranker(8010) 延迟 | 重启 embedding/reranker 容器 |

### 10.3 Agent 问题

| 问题 | 排查步骤 | 解决方案 |
|------|---------|---------|
| "服务不可用" | 1. 检查 LLM API Key 2. 检查 API 额度 | 配置正确的 API Key，充值额度 |
| 工具调用失败 | 1. 查看错误信息 2. 检查对应服务状态 | 根据错误信息修复对应服务 |
| 实时行情返回空 | 检查是否在交易时段 | A股交易时间：工作日 9:30-11:30, 13:00-15:00 |

### 10.4 OA/CRM 问题

| 问题 | 排查步骤 | 解决方案 |
|------|---------|---------|
| Odoo 打不开 | `docker ps` 检查 odoo 容器 | `docker restart aiagent_odoo` |
| Twenty 打不开 | `docker ps` 检查 twenty 容器 | `docker restart aiagent_twenty` |
| 审批找不到审批人 | 检查员工 Manager 配置 | 在 Odoo 员工记录中设置直属经理 |
| Agent 操作 OA 失败 | 检查用户映射表配置 | 联系管理员配置 JWT→OA/CRM 身份映射 |

### 10.5 飞书/钉钉机器人问题

| 问题 | 排查步骤 | 解决方案 |
|------|---------|---------|
| 搜索不到机器人 | 检查应用是否已发布 | 在开放平台发布应用 |
| 机器人不回复 | 1. 检查后端日志 2. 检查 app_id/app_secret | 修正配置，重启后端 |
| 审批操作失败 | 检查审批模板是否配置 | 在飞书/钉钉管理后台配置审批模板 |

### 10.6 Docker 常用命令

| 命令 | 用途 |
|------|------|
| `docker compose up -d` | 启动所有服务 |
| `docker ps --filter "name=aiagent"` | 查看服务状态 |
| `docker logs aiagent_main-service --tail 50` | 查看 main-service 日志 |
| `docker restart aiagent_embedding` | 重启 embedding 服务 |
| `docker compose up -d --build` | 重建并启动（配置变更后必须执行） |
