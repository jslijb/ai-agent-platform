# 评估可靠性调研（EVALUATION RELIABILITY RESEARCH）

> ⏳ 需审批：本调研方案需审批通过后方可实施改造
> 最后更新：2026-08-04

---

## 1. 问题概述

当前评估系统 V13-r6 综合得分 0.9153（达标），但评估可靠性存在系统性风险，可能高估系统真实能力。

## 2. 已识别的6大问题

### 问题1：LLM 自评 LLM（🔴 严重）

**现状**：14个评估指标中9个依赖 LLM 评分（Faithfulness/Answer Relevance/Answer Correctness/Context Recall/Compliance/Hallucination/Planning/Consistency/Refusal Accuracy）

**风险**：
- 用同一个 LLM 评估自己的输出，存在"自我肯定"倾向
- LLM 评分缺乏校准，不同模型评分差异大
- 评分 prompt 可能引导 LLM 给高分

**证据**：
- V14 官方 RAGAS 库评分仅 0.3205，自实现评分 0.9153，差距巨大
- Faithfulness 指标自实现得分接近1.0，官方库接近0.5

**行业实践**：
- Google RAGAS 框架：使用独立 judge 模型（如 GPT-4）评估
- MLflow LLM 评估：人工标注金标准 + LLM 辅助
- 金融领域：监管要求人工审核 AI 输出

### 问题2：测试集规模小（🟡 中等）

**现状**：qa-golden.json ~40条用例，Agent 评估仅20条

**风险**：
- 40条样本的95%置信区间约 ±15%，0.9153 的真实值可能在 0.77-1.0 之间
- 无法覆盖金融场景的长尾情况
- 统计上不具显著性

**行业实践**：
- RAGAS 官方建议 ≥100 条
- 金融风控测试集通常 ≥500 条
- NIST AI 评估框架建议分层抽样

### 问题3：数值精度宽松（🟡 中等）

**现状**：Numerical Accuracy 评分规则：
- 误差 < 0.001 → 1分
- 误差 ≤ 0.05 → 0.5分
- 误差 > 0.05 → 0分

**风险**：
- 金融场景5%误差可能导致投资决策失误
- "半对"机制降低了评估区分度
- 实际使用中用户不会接受5%误差的财务数据

**行业实践**：
- 金融数据精度要求：误差 < 0.01%（4位有效数字）
- SEC 披露要求：精确到美元
- 建议改为：< 0.1% → 1分，< 1% → 0.5分，> 1% → 0分

### 问题4：无对抗测试（🟡 中等）

**现状**：测试集缺少故意诱导幻觉的用例

**风险**：
- 无法评估系统对"陷阱问题"的鲁棒性
- 金融场景中幻觉（编造数据）后果严重
- 当前100%通过率可能只是测试集不够难

**建议增加**：
- 编造的股票代码/财报数据
- 过时数据查询（如查询2020年实时股价）
- 不存在的指标查询
- 跨市场混淆（A股代码查港股数据）

### 问题5：Agent 评估样本不足（🟡 中等）

**现状**：Agent 端到端评估仅20条，工具匹配率85%

**风险**：
- 20条样本的置信区间约 ±22%
- 无法区分85%是真实能力还是随机波动
- 缺少多轮对话、错误恢复等复杂场景

### 问题6：启发式降级（🟡 中等）

**现状**：Context Relevance 在 @reaatech/rag-eval-metrics 库不可用时降级为 Jaccard 相似度

**风险**：
- Jaccard 仅衡量词重叠，无法评估语义相关性
- 检索"五粮液营收"返回"五粮液净利润"，Jaccard 高但语义偏
- 低估检索质量，但也可能掩盖检索缺陷

## 3. 改造方案（待审批）

### 方案A：渐进式改造（推荐）

| 阶段 | 内容 | 工作量 | 风险 |
|------|------|--------|------|
| Phase 1 | 扩充测试集到100条，增加对抗用例 | 2天 | 低 |
| Phase 2 | 引入独立 judge 模型（GPT-4/Claude）评估 | 3天 | 中 |
| Phase 3 | 收紧数值精度阈值 | 1天 | 低 |
| Phase 4 | 人工标注50条金标准，校准 LLM 评分 | 5天 | 中 |
| Phase 5 | 定期交叉验证（自评估 vs 人工 vs 独立模型） | 2天 | 低 |

### 方案B：全面重构

- 使用 RAGAS 官方框架替代自实现
- 工作量大（2周），风险高（V14官方评分仅0.32）
- 不推荐：当前自实现虽有问题但更贴合业务

### 预期效果

- 评估分数可能下降（从0.9153降至0.7-0.8），但更真实
- 发现更多系统弱点，指导针对性优化
- 建立评估可信度，避免"自说自话"
