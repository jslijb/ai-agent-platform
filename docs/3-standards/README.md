## SDD 三层文档（spec → design → task）

| 文档 | 定位 | 用途 |
|------|------|------|
| [spec.md](spec.md) | WHAT（做什么） | 需求规格，变更后必须级联更新design和task |
| [design.md](design.md) | HOW（怎么做） | 技术设计，写代码最终参考task.md |
